# AGENTS.md

## Commands

- Package manager is **npm** (only `package-lock.json` exists). Do not use yarn/pnpm/bun.
- `npm run dev`, `npm run build`, `npm run start`, `npm run lint` (`lint` = `eslint` with the flat config in `eslint.config.mjs`).
- There is **no test script and no typecheck script**. Verify changes in this order:
  1. `npm run lint`
  2. `npx tsc --noEmit`
  3. `npm run build` — runs the TypeScript check but **not** ESLint, so lint must be run separately.
- In a **clean checkout/worktree**, `npx tsc --noEmit` fails with
  `Cannot find name 'LayoutProps'` until `.next/types` exists — that type is
  generated by `next build`/`next dev`, not checked in. Run `npm run build` once
  first; the error is not a real type error. A fresh checkout also needs `npm ci`
  before any `next` command works.
- Build/dev run on Turbopack (Next.js 16 default). The CSS toolchain in `next.config.ts` is wired through `turbopack.rules`, so a webpack build would lose Tailwind.

## Project shape

- Single Next.js 16 App Router app under `src/app`. No monorepo/workspaces.
- `next`, `eslint-config-next`, `react`, `react-dom` are **exact-pinned** (no `^`)
  in `package.json`; everything else is caret-ranged. Bump `next` and
  `eslint-config-next` to the same version in one change.
- Path alias `@/*` → `./src/*` (tsconfig).
- Shared types live in `src/types/bangalNews.types.ts` — the filename spells **"bangal"**, not "bangla".
- All data fetching is inline `fetch()` in server components against the public API
  `https://news-api-v2.vercel.app`:
  `/api/news`, `/api/news/sections`, `/api/news/most-read`, `/api/categories`,
  `/api/category/{slug}`, `/api/article/{id}`.
  No env vars, no `.env` file, no local API/service layer.
- Response convention: unwrap `data.data`; call `notFound()` when `!res.ok`.

## Next.js quirks that bite

- `next.config.ts` enables `cacheComponents` + `partialPrefetching`. Every server component
  that fetches must sit inside `<Suspense>` with a skeleton fallback (see `src/app/page.tsx`
  and the `*Skeleton.tsx` components), and fetches use `next: { revalidate: 60 }`.
- `images.remotePatterns` allows **only `ichef.bbci.co.uk`** — any other image host throws at
  runtime. `images.qualities` is `[75, 100]`.
- Route `params` is a Promise: `const { articleId } = await params`.
- Tailwind v4 + daisyUI v5, configured as `@import "tailwindcss"; @plugin "daisyui";` in
  `src/app/globals.css`. There is no `tailwind.config` file.
- UI is Bengali: dates use locale `bn-BD` and timezone `Asia/Dhaka` (see
  `src/components/NewsCard.tsx`); keep that when adding date rendering.
